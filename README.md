# Bifold Door Hardware & Installation Kit

## 📌 Project Overview
This repository serves as the master documentation hub for the modular Bifold Door Hardware Kit. While the 3D CAD models and motion studies are maintained in a separate repository, this repository contains the 2D manufacturing drawings, cut sheets, Bill of Materials (BOM), and end-user installation manuals. 

This kit is designed to be scalable, supporting both **2-panel** and **4-panel** configurations for closet or room divider applications. It includes all necessary pivots, brackets, tracks, and fasteners required for a complete installation.

## 🛠️ Kit Features
*   **Complete Hardware Solution:** Includes every screw, anchor, bracket, and pivot needed for installation—no need to source missing parts.
*   **Scalable Configuration:** The same hardware kit can be used for standard 2-panel doors or scaled to a 4-panel system for wider openings.
*   **Adjustable Design:** Slotted holes in the Top and Bottom brackets allow for ±5mm height and depth adjustments to ensure a perfect fit against the door frame.
*   **Floor Protection:** The Guide Wheel Assembly features a nylon wheel to ensure smooth operation without scratching hardwood or tile floors.

## 🚀 Installation Summary

**Step 1: Mount the Track**
*   Secure the **U Channel Aluminum Rail** to the header using the HW-001 flat head screws. Ensure the track is level.

**Step 2: Assemble the Door Panels**
*   Connect your door panels using the **Non Morse Hinges** and HW-002 screws. 
*   Attach the **Handle** to the leading edge using the HW-006 machine screws.

**Step 3: Install Pivots & Brackets**
*   Attach the **Bottom Bracket** and **Bottom Pivot** to the outer door panel.
*   Install the **Top Bracket** and **Top Metal Pivot** into the top track.

**Step 4: Hang the Doors**
*   Lift the door assembly, hook the top pivot into the track bracket, and align the bottom pivot into the bottom bracket.
*   Adjust using the HW-005 M6 screws until the door sits perfectly level.

**Step 5: Floor Guide**
*   Mount the **Guide Wheel** to the floor using the HW-003 anchors/screws, aligning it with the center gap of the folding doors.

*For a detailed, step-by-step visual guide, please refer to the `Installation_Manual.pdf` in the `/docs` folder.*
